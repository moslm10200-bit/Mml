# موقع بيع المشروبات

موقع عربي (من اليمين لليسار) بسيط وسريع، بدون تسجيل دخول وبدون بريد أو كلمة سر.

## التشغيل
افتح `index.html` في المتصفح مباشرة، أو ارفع كل الملفات على أي استضافة (Netlify، GitHub Pages، Firebase Hosting...).

## الملفات
- `index.html`: هيكل الصفحة (السلة أعلى اليمين، البانر، البحث، المنتجات).
- `styles.css`: التصميم. الخلفية متدرجة أزرق/بنفسجي تغطي الموقع كاملاً، والحاوية `width:100vw; max-width:100%; margin:0; padding:0`.
- `products.js`: **أهم ملف للتعديل** — رقم الواتس اب، العملة، صور البانر العلوي، والمنتجات وأسعارها.
- `app.js`: منطق الموقع (السلة، البحث، الشراء عبر واتس اب).
- `firebase-config.js`: بيانات Firebase (اختيارية).
- `firebase-adapter.js`: يحفظ الطلبات في Firestore إذا فعّلته.

## تغيير الصورة العلوية
في `products.js` عدّل `HERO_SLIDES`:
```js
{ image: "images/banner.jpg", title: "العنوان", subtitle: "النص تحت العنوان" }
```
- ضع أكثر من عنصر لتتحرك الصور تلقائياً، وغيّر السرعة من `HERO_INTERVAL`.
- إذا تركت `image` فارغة تظهر خلفية ملونة حسب `colors`.

## إضافة منتج
أضف سطراً في `PRODUCTS`:
```js
{ id: 10, name: "اسم المشروب", price: 15000, color: "#f472b6", image: "images/p10.jpg" }
```
- `id` يجب أن يكون فريداً.
- إذا تركت `image` فارغة يُرسم كوب بلون `color`.

## الشراء عبر واتس اب
عند الضغط على «شراء» يُضاف المنتج للسلة. في السلة زر أخضر «انقر للشراء عبر واتس اب» يفتح واتس اب على الرقم `963992147669` ويكتب اسم المنتج والكمية والمجموع تلقائياً في المحادثة. لتغيير الرقم عدّل `whatsapp` في `products.js`.

## تفعيل Firebase (اختياري)
1. أنشئ مشروعاً في Firebase وفعّل Firestore.
2. ضع بياناتك في `firebase-config.js` وغيّر `enabled` إلى `true`.
3. ستُحفظ الطلبات في مجموعة `orders` عند كل عملية شراء. اضبط قواعد Firestore بحيث تسمح بالإضافة فقط.
